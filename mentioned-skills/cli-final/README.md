# `cli-final` — Project Completion & GitHub Release Cleaner

`cli-final` is invoked when a software project is finished. It automatically cleans up temporary development spec files (`PRD.md`, `Architecture.md`, `Rules.md`, `Phases.md`, `Design.md`, `Memory.md`, `GEMINI.md`, `CLAUDE.md`), verifies build integrity, and prepares the repository for a clean push to GitHub.

## ⚡ Usage

```text
/cli-final
```

or

```text
/cli-skills:final
```
